# HesapSat – Dijital Hesap Al & Sat Platformu

**HesapSat**, [hesapsat.net](https://hesapsat.net) benzeri bir **Türkçe dijital hesap pazar yeri** platformudur.  
Oyun hesapları, sosyal medya, streaming ve yazılım lisanslarının güvenli şekilde alınıp satıldığı tek sayfalık bir web uygulamasıdır.

---

## 📌 Proje Hakkında

| Özellik | Bilgi |
|---|---|
| **Platform Türü** | hesapsat.net benzeri dijital hesap marketplace |
| **Teknoloji** | Tek sayfa HTML (vanilla HTML + CSS) |
| **Dil** | Türkçe |
| **Hedef Kitle** | Dijital hesap alıcı ve satıcıları (Türkiye) |

---

## 🚀 Temel Özellikler

- 🎮 **Oyun Hesapları** – CS2, Valorant ve daha fazlası
- 📱 **Sosyal Medya** – Instagram, Twitter vb.
- 🎬 **Streaming** – Netflix, Spotify, vb.
- 💻 **Yazılım & Lisans** – Microsoft Office, vb.
- 🛡️ **Emanet Sistemi** – Güvenli ödeme: para satıcıya teslim sonrası aktarılır
- ✅ **Doğrulanmış Satıcılar** – Kimlik doğrulaması yapılmış satıcı ağı
- ⚡ **Anında Devir** – Onay sonrası hesap dakikalar içinde teslim
- 🔄 **İade Güvencesi** – Ürün açıklamaya uymuyorsa tam iade
- 💬 **7/24 Canlı Destek**
